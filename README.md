# VELLIUM

Тёмный лендинг и первая работающая версия личного дневника питания. Приложение рассчитано на русский интерфейс и мобильный экран.

## Запуск

```powershell
npm install --silent
npm run dev --silent
```

Лендинг открывается на `/`, дневник — на `/app`.

## Что работает сейчас

- Личный профиль взрослого пользователя и ориентир энергии/БЖУ по формуле Миффлина — Сан Жеора с ручной настройкой калорий.
- Ручной ввод блюда с пересчётом пищевой ценности с 100 г на указанную порцию.
- Дневной баланс, история за последние семь дней, удаление записи.
- Идея следующего блюда из небольшого локального списка после первой записи. Подсказка ориентируется на остаток калорий и белка, не выдаётся за медицинский совет.
- Экспорт локальных записей в JSON и удаление данных с этого устройства.

Профиль и записи пока хранятся **только в localStorage этого браузера**. Очистка данных браузера удалит их. Облачные аккаунты, семейные профили, распознавание фото и сканер не включены; на лендинге они обозначены как функции следующих этапов. Не вводите реальные персональные данные для совместного использования или производственного запуска до внедрения авторизации, RLS и резервного копирования.

## Следующие этапы

1. Отдельный проект Supabase: схема, Auth, RLS и проверка изоляции двух пользователей.
2. Серверный FastAPI для распознавания фото, текста и аудио через Gemini с подтверждением результата перед записью.
3. Сканер штрихкодов/GS1 DataMatrix и каталог продуктов с проверяемым источником.
4. Семейные профили, история и аналитика, Excel, PWA и доступность на реальных устройствах.
5. Аудит VPS, резервная копия старого сайта и отдельный план размещения без вмешательства в действующие сервисы.

Перед хранением данных российских пользователей в облаке за пределами РФ нужно проверить применимость требований о локализации персональных данных. До этого шага текущая версия не передаёт дневник на сервер.
